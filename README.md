📝 To-Do List App

A simple and interactive To‑Do List application built to practice core web development concepts.  
This project helps users organize tasks efficiently with features like adding, editing, marking complete, and deleting tasks.

## 🚀 Features
- Add new tasks
- Edit existing tasks
- Mark tasks as completed
- Delete tasks
- Persistent storage using localStorage (tasks remain after page reload)

## 🛠️ Tech Stack
- **HTML5** – structure
- **CSS3** – styling
- **JavaScript (ES6)** – functionality
